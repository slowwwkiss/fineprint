        How the hybrid engine works

        FinePrint uses Firebase AI Logic with one hybrid model (InferenceMode.PREFER_ON_DEVICE). The SDK checks for a local model first: on Chrome desktop that is Gemini Nano through the Prompt API. If no local model is available, the same call falls back to Gemini 2.5 Flash in the cloud. Long documents are chunked and analysed in the cloud, because they do not fit the on-device model. Every answer carries its inferenceSource — the badge above each verdict is read from the response itself, not guessed.

        • Firebase AI Logic — hybrid inference (Gemini Nano ↔ Gemini 2.5 Flash)
        • App Check — protects cloud calls (reCAPTCHA v3; debug token in development)
        • Authentication — anonymous sign-in, no account needed
        • Firestore — your analysis history, per anonymous user
        • Remote Config — routing thresholds, tunable without a redeploy
